# BIOLOGY FLOW
7 және 8-сыныптардың 1-тоқсанына арналған авторлық интерактивті биология экожүйесі.

## Жаңа мүмкіндіктер
- әр сабаққа арналған 45 минуттық үш кезең: сабақтың басы, ортасы және соңы;
- кезеңдерді ретімен ашатын құлып жүйесі және сабақ таймері;
- әр кезеңдегі бағалау критерийі мен үш нақты дескриптор;
- 10 ұпайлық бағалау: сабақ басы — 2, ортасы — 5, соңы — 3 ұпай;
- сабақ соңындағы жеке нәтиже: пайыз, деңгей, кезеңдік ұпай, уақыт және ұсыныс;
- мұғалімге арналған бөлек мәзір: Басқару тақтасы, Оқушылар мониторингі, Оқу аналитикасы, Көмек сигналдары;
- 7/8-сынып сүзгісі, сабақтардың меңгеру картасы және кезеңдік аналитика;
- 70%-дан төмен нәтиже мен «Көмек керек» рефлексиясын автоматты анықтау;
- оқушының жеке аналитикалық карточкасы және CSV есеп жүктеу;
- Тіркелгеннен кейін автоматты ашылатын «Менің профилім»;
- XP, деңгей, күндік серия және 8 цифрлық бейдж;
- 16 сабақтан тұратын жеке зерттеу маршруты;
- WOW-интерактив, виртуалды микроскоп, жасуша сканері;
- оқу мақсатына сай Drag & Match сәйкестендіру ойыны;
- органоидтарды орналастыратын Cell Builder;
- фокус пен үлкейтуді басқаратын Virtual Microscope;
- дәрумен тапшылығын анықтайтын «Ағзаны құтқар» миссиясы;
- көмірсу, нәруыз және липидті анықтайтын Food Detector;
- тоқсанды қорытындылайтын үш бөлмелі BIO Escape Room;
- 7-сынып КТЖ-сына сай 16 сабақ: экожүйелер, тірі ағзаларды жүйелеу, жасушалық биология, су және органикалық заттар;
- 7-сынып сабақтарының тақырыптары мен оқу мақсаттары 2026–2027 оқу жылына арналған КТЖ-дан енгізілді;
- Brain Check, эмоциялық рефлексия және ғылыми журнал;
- мұғалімге арналған сынып аналитикасы.

## Демо кіру
Мұғалім: `teacher` / `bio2026`  
Оқушы профилін бірден көру үшін басты беттегі **«Демо-профильді көру»** батырмасын басыңыз.

API_URL бос кезде оқушы тіркелуі мен прогресс браузердің localStorage жадында жұмыс істейді. Сондықтан GitHub Pages-қа бірден жүктеп, интерфейсті тексеруге болады.

## Google Sheets қосу
1. Google Sheets ашыңыз.
2. Extensions → Apps Script.
3. `Code.gs` кодын көшіріңіз.
4. Deploy → New deployment → Web app.
5. Execute as: Me; Who has access: Anyone.
6. Web app URL-ін көшіріп, `app.js` ішіндегі `API_URL` айнымалысына қойыңыз.

Егер бұрынғы нұсқа жарияланған болса, жаңартылған `Code.gs` кодын қойып, **Deploy → Manage deployments → Edit → New version → Deploy** арқылы қайта жариялаңыз. 7-сынып сабақтары кестеде `701–716`, 8-сынып сабақтары `801–816` кодтарымен бөлек сақталады.

## GitHub Pages
Барлық файлды репозиторий түбіріне жүктеңіз: index.html, style.css, app.js. Settings → Pages → Deploy from branch → main / root.

## Маңызды
Жергілікті демо режимінде дерек сол браузерде сақталады. Оқушылар әр құрылғыдан кіретін нақты қолданыс үшін Google Sheets байланыстырыңыз. Өндірістік нұсқада мұғалім аутентификациясын және Apps Script API рұқсаттарын күшейткен дұрыс.
